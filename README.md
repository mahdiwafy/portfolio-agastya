## 🛠️ Fitur & Struktur Halaman Web

Sesuai dengan **Buku Panduan Tutorial Pembuatan Website Portofolio Ameliorer Day 5**:
1. **About Me (Tentang Saya):** Profil personal, identitas lengkap (Nama, NIM, Prodi, Kelompok 16_Gateway), latar belakang, dan aktivitas mahasiswa.
2. **What I Can Do (Keahlian & Alat):** Penguasaan kompetensi basis data (MySQL, SQLite), pengembangan web semantik (HTML5, CSS3, JavaScript), pemodelan proses bisnis (BPMN), serta pembukuan kas digital.
3. **Work Gallery (Karya & Proyek):** Showcase 4 proyek representatif sistem informasi dan perancangan aplikasi.
4. **Achievement (Prestasi & Sertifikasi):** Pencapaian kompetisi analisis data spreadsheet, sertifikasi kompetensi kejuruan, dan kepengurusan bendahara angkatan.
5. **Contact (Kontak & Berkas):** Tautan komunikasi resmi (Email SSO, GitHub, WhatsApp) serta tombol unduh berkas **CV ATS** format PDF (`./assets/cv/CV_Agastya_Atthariz_Maulana.pdf`).
